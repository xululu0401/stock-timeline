# 补货时间线

单物品逐日库存情景工具。纯前端、无API依赖。输入库存、分段需求、到货日序，对比统一延误并计算消除区间缺口的最小期初追加量。

## 开发
- `node build.cjs` 合成 index.html。
- `node --test tests/core.test.cjs` 核心测试。
- `python3 -m http.server 8819 --bind 127.0.0.1` 后浏览器打开本机地址。
- 封面生成依赖 sharp，修改 make-cover.cjs 中 sharp 路径为本机安装位置；应用本身没有第三方依赖。

## 口径
当日先到货、再消耗，需求未满足当天丢失，不结转。最小追加为最大累计供需缺口。1–180天，整数数量，20阶段/60到货批次；不包含容量、保质期、安全库存与随机性，不是采购预测。

## 验证
6项核心测试、400场景独立逐单位消耗及追加量穷举；真实浏览器测试输入变化、补足、错误隐藏、保存刷新、JSON备份往返、CSV/MD/JSON/PNG下载。390px默认与180天大数排版检查，图表采用响应宽度以保持刻度可读。

示例：40盒期初，7天每日8盒、再7天每日12盒，第4/10天到40/60盒。正常无缺口；延误3天时第6天首次缺口，累计36盒，最小期初追加36盒。示例完全虚构。
